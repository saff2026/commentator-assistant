# مساعد المعلّق 🎙️

تطبيق ويب عربي يساعد المعلّق الرياضي في التحضير للمباراة وأثناء التعليق.

- **الدوريات:** دوري روشن السعودي، الإنجليزي، الإسباني، الإيطالي، الألماني، الفرنسي.
- **التحضير:** الترتيب، آخر المباريات، المواجهات السابقة، الحكم والملعب، التشكيلات، وملاحظات خاصة تُحفظ على الجهاز.
- **السجل الكامل:** مباريات كل فريق موسمًا بموسم (آخر ١٠ مواسم)، وتفاصيل أي مباراة سابقة (الأهداف والبطاقات والتبديلات والتشكيلات والإحصائيات)، وسجل كل لاعب مباراة بمباراة، وكل المواجهات بين فريقين مع هدافيها.
- **مباشر:** تحديث تلقائي كل ٢٠ ثانية واقتراحات معلومات مع كل هدف أو بطاقة أو تبديل أو تغيّر في الإحصائيات.
- **مصدر البيانات:** خدمة بيانات ESPN الرياضية، مع روابط للمواقع الرسمية للدوريات للتحقق.

التطبيق ملف واحد (`index.html`) لا يحتاج إلى تثبيت.
